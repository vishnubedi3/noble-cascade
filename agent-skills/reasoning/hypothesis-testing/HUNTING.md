# Hypothesis Testing Skill (Cloudflare Security Audit Skill)

## Methodology
Systematic exploration of codebase attack surfaces:
- Injection flaws (SQLi, Command Injection, XSS, SSRF)
- Authentication and Session Management bypasses
- Access Control failures (IDOR, privilege escalation)
- Business logic flaws and cryptographic weaknesses
- AI/LLM specific vulnerabilities (prompt injection, tool poisoning)
