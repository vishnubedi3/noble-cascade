# Severity Assessment Skill (Anthropic Cybersecurity Skills)

## Framework Mapping
Maps identified vulnerabilities to CVSS 3.1 / 4.0 metrics, Common Weakness Enumeration (CWE), OWASP Top 10, and MITRE ATT&CK / ATLAS techniques.
- **Critical:** Remote code execution, authentication bypass, hardcoded master secrets.
- **High:** SQL injection, IDOR with data access, privilege escalation.
- **Medium:** XSS, CSRF, insecure configuration defaults.
- **Low:** Information disclosure of non-sensitive metadata, minor header omissions.
